# Ảnh chocolate

- `01.svg` … `12.svg`: ảnh tạm vẽ tay (nhìn từ trên xuống, nền trong suốt). Thay bằng ảnh thật bằng cách ghi đè đúng tên file, hoặc đổi trường `image` trong `data/chocolates.json`.
- `fallback.svg`: ảnh thay thế khi viên thiếu file ảnh hoặc ảnh tải lỗi.
- Ảnh thật: vuông 1:1, nhìn từ trên xuống, nền trong suốt (PNG/WebP), từ 800px, viên nằm giữa và chiếm khoảng 80% khung.

Chi tiết: `data/README.md`.
